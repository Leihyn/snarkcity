# SnarkCity

Sealed launches. Public prices.

SnarkCity is a token launchpad where bids are shielded Zcash payments. During a launch, nobody can see who is bidding or how much. When the auction closes, everyone pays the same public clearing price, tokens are claimed on Solana, and anyone can audit the raise from its published viewing key.

Built for ZECATHON (Private Markets track). Work in progress.
